## 3. 과일·야채 섹션 `#fresh`

- 위치: `#service` 다음 · `#stores` 앞. 라벨 `SERVICE · FRESH DAILY`
- 진입점: 히어로 「**매일 입고** 신선한 과일·야채 — 공구방 참여만 해도 회원가 →」 · 모바일 메뉴 「매일 신선 과일·야채」(서비스 다음)
  - 헤더(데스크톱) 메뉴에는 넣지 않는다 — 이 구간은 「서비스」가 활성 표시
- 사진 3장 `assets/images/products/fresh-{yeoul,hoban,sujin}.webp`
  - 원본: 사용자 제공 3000×4000 (카톡 받은 파일 `동탄여울.jpg` · `호반서밋.jpg` · `성남수진.jpg`)
  - 동탄여울 16:9 (1280×720) — 위 「가락특송×앤드마켓」 현수막 · 아래 대파 「회원가」 가격표가 빠지게 크롭
  - 호반써밋 4:3 (1200×900) — 위 「24시간 OPEN」 · 「이름없는 과일가게」 간판 · 창문 가격표 제외, 팽이버섯 「회원가」 글자만 흐림
  - 성남수진 4:3 (1200×900) — 카운터 직원 얼굴이 안 나오게 아래쪽 크롭
- 카드 2개
  - **예약으로 받기**: 공구방에서 확인 → 앱·공구방에서 예약 → 매장에서 「나의 QR」 픽업 · CTA 앱 예약(`order.andmarket09.com`) / 공구방(매장 선택 모달)
  - **매장에서 바로 사기**: 상설 3개 매장 · 회원가 안내 칸 · CTA 「공구방 참여하고 회원가로」(모달) / 매장 위치 보기
- FAQ 첫 문항 「과일·야채는 어떻게 살 수 있나요?」 · FAQ 머리말 「매장 이용과 가맹에 대해…」
- SEO: meta description · keywords(과일 야채 · 동탄/성남 과일 야채) · `sitemap.xml` `#fresh`

## 4. 카카오톡 채널 숨김

- 원인: 채널 `pf.kakao.com/_JjRfX` 의 **1:1 채팅이 꺼져** `/chat` 이 「채팅이 불가능한 프로필입니다. 해당 채널은 더 이상 채팅 기능을 사용하지 않습니다.」로 열림. 홈페이지 코드 문제 아님(링크는 예전 그대로).
- 삭제: 플로팅 「카톡상담」 · 오늘의 공구특가 「공동구매 문의하기」 · 푸터 채널 링크
- 변경: 매장 선택 모달 안내 → 「매장마다 공구방이 따로 있습니다. 가까운 매장을 골라 입장해 주세요.」 · 푸터 고객문의 → 「매장별 카카오톡 공구방」
- 유지: JSON-LD `sameAs`(화면 비노출) · `.floating-kakao` CSS(복구용)
- **복구 조건**: 채널 관리자센터(center-pf.kakao.com) › 채팅 설정 › 1:1 채팅 켜기 → 사용자가 알리면 링크만 되살린다.
