## 2. PR #27 — 디자인 리프레시 (`design/refresh`)

### 구조: 섹션 17 → 12

| 변경 전 | 변경 후 |

| BUSINESS MODEL + DIGITAL & PICKUP(`#how`) + OPERATION(`#operation`) | `#business` — 5단계 타임라인 1개 + 「운영하는 사업」 목록 |

### 디자인 시스템 (상세 규칙은 `claude.md` 「디자인 시스템」)

- 색: 로고 추출 — 오렌지 `#ff9000` · 크림 `#fef5e2` · 먹색 `#231e18`. 초록은 `#fresh` 전용. 글자용 오렌지 `#a85700`(대비 4.5:1↑), 오렌지 버튼 글자는 먹색
- 흰 카드 그리드 → 가는 선(hairline) 레이아웃. 사진만 둥근 모서리
- 둥글기 3단계(8 / 16 / 원형) · 그림자 1종(모달) · 알약은 버튼·운영중만
- 섹션 머리: 왼쪽 정렬 · 한글 라벨(짧은 오렌지 선) · 제목 왼쪽/설명 오른쪽
- 어두운 섹션은 가맹문의만(서비스·비전의 남색 배경 제거)
- 이모지 → CSS 도형(햄버거·닫기 X·점·선) · 한글 자간 `-.025 ~ -.035em` · 스크롤 모션 24 → 16px

### 콘텐츠

- 오늘의 공구: 색 상자 3개 삭제 → 실사진(`product-fresh-apple.webp`) + 카테고리 목록(4번째 「매장 픽업」 → 「생활상품」)
- 준비중 매장: OPEN SOON 카드 3장 → `.store-soon` 한 줄
- 문구: 「AI 시스템으로 발굴」 → 「산지와 브랜드사에서 직접 찾아옵니다」 · 「단순 ○○가 아니라」 · 제목 줄표 · 「하나의 ○○으로」 정리
- 히어로 키워드 칩 삭제(「모바일 주문」 — 금지 명칭 「모바일오더」와 유사 — 포함)
- 「업소 대상 가락식자재 배달」 → 「업소 대상 식자재 배달」(「가락특송」 금지 규칙과 혼동 방지)
- FAQ 「카카오톡 채널 안내」 → 「카카오톡 공구방 안내」(채널 숨김 상태 반영)
- 서비스 3축 「주문할 때 / 받을 때 / 그 뒤에서」 표기는 유지

### 작업 중 잡은 버그

- `<img>` 의 `height` 속성이 CSS `aspect-ratio` 를 덮어써 사진이 세로로 늘어남 → 전역 `img { height: auto }`
- 매장 카드 배지 `em.model` 이 매장 모델 섹션의 `.model`(padding 28px)과 이름 충돌 → `em.store-model` 로 변경
- 과일·야채 갤러리: 큰 사진이 행 높이를 키움 → 큰 사진 `height: 0; flex: 1` 로 오른쪽 두 장 높이에 맞춤
- 가맹문의 STEP 목록에 위 체크리스트 스타일이 번짐 → `.partner-copy > ul li` 로 범위 축소

## 3. PR #28 — 헤더 정리 (`fix/header-clean`)

| 항목 | 변경 |
|---|---|
| 헤더 로고 이미지 | 삭제 (푸터·파비콘 로고는 유지) |
| 헤더 오른쪽 「카카오톡 공구방」 버튼 | 삭제 → 메뉴를 오른쪽 끝으로. 모바일 햄버거 메뉴 안 공구방 항목·본문 CTA 는 유지 |
| 헤더 글자 깨짐 | 반투명 배경 + `backdrop-filter: blur()` 제거 → 불투명 `var(--paper)` |
| 메뉴 글자 | 15px/600 → 16px/500 |
| 브랜드 글자 `Cafe'andMarket` | 검정 700 → 진회색(`--ink-2`) 600 + 'and' 만 오렌지 `#e07a00`(`.brand-and`) — 시안 4종 중 A안(사용자 선택) |
| 히어로 상단 「카페앤드마켓 · 앤드마켓」 | 삭제 (미사용 `.eyebrow` CSS 정리) |

**글자 깨짐 원인**: 반투명 배경 위 `backdrop-filter` 가 걸린 요소는 Windows Chrome 이 ClearType(서브픽셀) 대신 흑백 안티앨리어싱으로 그린다 → 본문보다 거칠고 흐리게 보임. 헤더 배경은 **불투명 단색**으로 유지한다(CSS 주석에도 기록).
검수용 헤드리스 크롬은 원래 흑백 렌더링이라 차이를 재현할 수 없음 → 실제 PC 확인은 사용자 몫.
